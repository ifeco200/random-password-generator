# Random Password Generator

A simple random password generator built with HTML, CSS and JavaScript. It generates a secure 14-character password and lets you copy it to the clipboard in one click.

## Features

- Generates a random 14-character password with letters, numbers and symbols
- Uses `crypto.getRandomValues()` for secure randomness
- One-click copy to clipboard
- "Password Copied" alert after copying
- Clean, responsive layout

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- [Font Awesome](https://fontawesome.com/) for the copy icon

## How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/random-password-generator.git
   ```
2. Open `index.html` in your browser.
3. Click **Generate Password**.
4. Click the copy icon to copy the password.
